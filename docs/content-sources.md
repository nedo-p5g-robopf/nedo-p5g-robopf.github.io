# コンテンツの編集ガイド

## 掲載範囲

- プロジェクトページでは産総研・川崎重工業・竹中工務店の3つのコンソの取組と参画機関を紹介します。
- コンソごとの目的・開発内容は `_data/consortia.yml`、参画機関と担当領域は `_data/members.yml` で管理します。各機関の `consortium` に `aist`・`kawasaki`・`takenaka` を設定してください。
- 研究成果一覧には産総研コンソの16の開発項目を掲載しています。16は公開済みソフトウェアの件数ではありません。
- 研究成果は、設計・開発／実装・検証／評価・導入／運用の4つの工程で分類します。

## 公開先の管理

- 各成果のMarkdownに `resource_url` を設定すると、公開先へのボタンが表示されます。
- リンク未掲載の成果は、サイトの案内に従って現時点で非公開として扱います。公開時にURLと導入手順・対応環境・ライセンスを確認し、掲載内容を更新してください。
- 配布リンクがない詳細ページには、次の案内を共通で表示します。

> このページは研究開発内容の紹介です。ソフトウェアの配布先は、個別のGitHubリポジトリなどをご参照ください。リンク未掲載の場合は、現時点で非公開の成果物となります。

## 更新時の確認

機関名・担当領域、公開URL、配布条件、問い合わせ窓口、対外公表可能な記述を確認してください。根拠が確認できない効果の数値・導入実績・認証取得等は補わず、研究開発の目的と機能を具体的に説明します。

トップページのマークとロボット図は、このサイト用の概念図です。正式ロゴを掲載する場合は使用条件を確認してください。
