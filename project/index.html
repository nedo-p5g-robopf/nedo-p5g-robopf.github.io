ABOUT THE PROJECT

BACKGROUND & MISSION

多様な現場に応える、
ソフトウェアの共通基盤。

人手不足への対応と生産性の向上に向けて、これまでロボットの導入が進んでいなかった領域での活用が求められています。多品種少量の作業や、人と接する複雑な環境では、従来の個別開発に加えて、柔軟で再利用しやすいソフトウェアが重要になります。

既存のオープンな開発環境を活かしながら、ソフトウェアの品質や信頼性を確認し、設計から現場導入までを支援する基盤を構築します。多様な開発主体が持つ技術を組み合わせ、ロボットSIの効率化と未活用領域への導入を推進します。

PROJECT ECOSYSTEM

3つのコンソが連携する、開発・流通基盤。

産業技術総合研究所、川崎重工業、竹中工務店の各コンソが、品質管理・開発支援、共通アーキテクチャ・基本機能、建設業向けのモジュール・ツールを分担。開発から検証、流通、現場での活用までをつなぎます。
