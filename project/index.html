ABOUT THE PROJECT

ロボットの可能性を、
未活用の領域へ。

柔軟な開発と、品質・信頼性・安全性の両立を目指して。

BACKGROUND & MISSION

多様な現場に応える、
ソフトウェアの共通基盤。

人手不足への対応と生産性の向上に向けて、これまでロボットの導入が進んでいなかった領域での活用が求められています。多品種少量の作業や、人と接する複雑な環境では、従来の個別開発に加えて、柔軟で再利用しやすいソフトウェアが重要になります。

本プロジェクトでは、既存のオープンな開発環境を活かしながら、ソフトウェアの品質や信頼性を確認し、設計から現場導入までを支援する基盤を構築します。多様な開発主体が持つ技術を組み合わせ、ロボットSIの効率化と未活用領域への導入を推進します。

PROJECT ECOSYSTEM

3つのコンソが連携する、開発・流通基盤。

NEDO事業全体では、共通アーキテクチャや開発・運用支援ツール、ユースケース向けモジュールを連携させる取組が進められています。本サイトでは、そのうち産総研コンソの研究開発成果を紹介します。

掲載情報について

本サイトは「CEATECスライド（統合、冒頭にコンソ概要）R01」をもとに、研究開発の目的・内容を紹介しています。成果の分類や説明は、利用場面に沿って整理したものです。最新の配布条件、対応環境、ライセンスは、各成果の公開先をご確認ください。

安全性評価やリスクアセスメントの支援ツールは、設計・評価の判断を支援するものです。ツールの利用だけで、個別のロボットシステムの安全性を保証するものではありません。
